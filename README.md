# Techinika Web — Company Website

Official website for [Techinika](https://techinika.co.rw), a Rwandan venture studio and media house.

## Ecosystem

- **Techinika News** — Rwanda's tech news platform
- **Agaseke** — Creator monetization platform
- **Apprena** — AI-powered career roadmaps
- **Ubuhanga** — Free tech tutorials in Kinyarwanda
- **Ubunifu Labs** — Custom software development

## Tech Stack

Next.js 15, TypeScript, Tailwind CSS v4
